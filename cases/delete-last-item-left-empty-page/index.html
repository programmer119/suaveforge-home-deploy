마지막 항목을 지웠더니 존재하지 않는 빈 페이지에 남았다

한 페이지의 마지막 항목을 삭제한 뒤 전체 페이지 수는 줄었는데 화면은 이전 페이지 번호에 남아 빈 목록을 보여줬다.

2026년 9월 3일Cases

목록의 한 페이지에 마지막 항목 하나가 남아 있었다. 그 항목을 삭제했다.

삭제 뒤 전체 페이지 수는 줄었지만 화면은 이전 페이지 번호에 그대로 남았다. 그 결과 목록에는 아무 항목도 보이지 않았다.

현재 페이지의 마지막 항목 삭제
전체 페이지 수 감소
화면은 이전 페이지 번호 유지
빈 목록 표시

삭제는 끝났지만 목록 위치는 끝나지 않았다

문제는 삭제 자체가 실패한 것이 아니었다. 데이터가 줄면서 더 이상 존재하지 않는 페이지를 화면이 계속 가리킨 것이 문제였다.

마지막 항목을 지운 뒤 현재 페이지가 없어졌다면 남아 있는 마지막 페이지로 이동하거나, 결과가 하나도 없다면 빈 상태를 보여줘야 한다. 삭제 뒤에는 행 하나만 제거할 것이 아니라 현재 페이지가 새 전체 건수에서도 유효한지 다시 확인해야 한다.
