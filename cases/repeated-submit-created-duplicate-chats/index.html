전송 버튼을 여러 번 누르자 상담 채팅도 여러 개 생겼다

Chatwoot의 사전 채팅 입력 화면에서 네트워크가 느릴 때 전송 버튼을 여러 번 누르면 클릭한 횟수만큼 별도 채팅이 만들어지는 문제가 보고됐다.

2026년 9월 4일Cases

Chatwoot의 사전 채팅 폼에서 네트워크 응답이 느린 상태로 제출 버튼을 여러 번 누르면 클릭할 때마다 새 채팅이 만들어지는 문제가 보고됐다.

사용자 화면에서는 메시지 하나만 보일 수 있었지만 관리자 화면에는 여러 채팅 기록이 생겼다. 문제 보고에서는 첫 제출 뒤 추가 클릭을 막거나 무시해 한 번의 제출에 채팅 하나만 만들어져야 한다고 설명했다.

네트워크 응답 지연
제출 버튼 반복 클릭
클릭할 때마다 새 채팅 생성
관리자 화면에 중복 채팅 기록

전송이 끝나기 전에 같은 작업이 다시 시작됐다

이 사례에서 확인된 사실은 반복 클릭이 각각 별도 제출로 처리됐다는 점이다. 한 번의 상담 시작에서 채팅 기록이 여러 개 생기지 않는지 최종 결과를 확인해야 한다.
