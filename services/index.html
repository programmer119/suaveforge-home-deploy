웹·앱 개발

웹사이트, 웹서비스, 모바일 앱, 관리자 시스템을 기획·개발·테스트·배포까지 연결합니다. 실제 프로젝트 화면과 기술 스택을 공개합니다.

LMS 개발

과정, 수강생, 진도, 운영 통계와 관리자 업무를 연결하는 LMS·교육서비스 개발. 공개 LMS 프로젝트와 자동화 사례를 기반으로 맞춤 구축합니다.

업무 자동화 개발

반복 입력, 문서 생성, 이미지 수집·검수, 예약 실행, 데이터 처리와 운영 업무를 Windows·웹·API 기반 프로그램으로 자동화합니다.

기존 소프트웨어 개선·재구축

낡거나 중단된 기존 소프트웨어를 실제 사용 흐름과 기술 구조로 진단하고, 살릴 부분은 유지하면서 필요한 개선·재구축·기능 추가를 진행합니다.
