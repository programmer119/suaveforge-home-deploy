삭제·필터 뒤 목록이 꼬일 때 확인하는 순서

삭제나 필터로 결과 수가 바뀌면 전체 페이지 수를 새 전체 건수와 페이지당 표시 개수로 다시 계산한다. 현재 페이지 번호가 새 범위 안에 있는지 확인하고, 화면에 보이는 행은 그 페이지의 새 조회 결과로 바뀌었는지 본다. 페이지 번호 목록과 이전·다음 버튼은 새 전체 페이지 수와 현재 페이지 번호에 맞게 표시되는지 확인한다.

삭제와 복구는 한 흐름으로 검수해야 한다
