중복 제출·중복 요청을 확인하는 순서

연속 클릭, Enter 한 번, 인증 뒤 화면 복귀, 폼 반복 제출을 각각 별도로 재현한다. 각 사례에서 확인할 결과가 다르므로 채팅 생성, 폼 제출 횟수, 생성 요청, 인증 오류, 고객 기록·세션 상태를 나눠 본다.

2026년 9월 4일Guides

재현 조건을 서로 섞지 않는다. 느린 네트워크에서 연속 클릭하는 시험은 따로 둔다. Enter 한 번, 인증 뒤 설정 화면 복귀, OTP 폼 반복 제출, 가입 폼 반복 제출도 서로 다른 시나리오로 실행한다.

시험확인할 것
느린 네트워크에서 연속 클릭클릭할 때마다 새 채팅이 만들어지는가
입력창에서 Enter 한 번폼 제출 동작이 두 번 발생하는가
인증 뒤 설정 화면으로 복귀복귀 뒤 같은 생성 요청이 다시 전송되는가
OTP 폼 반복 제출앞선 시도가 취소되거나 로그인 오류가 생기는가
가입 폼 반복 제출게스트 고객 기록이 두 개 생기거나 세션이 갈라지는가
