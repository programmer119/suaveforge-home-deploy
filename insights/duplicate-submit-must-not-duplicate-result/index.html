같은 작업이 다시 실행될 때 결과는 제품마다 달랐다

여러 제품에서 같은 제출이나 생성 요청이 한 흐름 안에서 다시 실행되는 문제가 보고됐다. 같은 계열 문제라도 시작 조건과 결과는 제품마다 달랐다.

2026년 9월 4일Insights

다섯 사례 중에는 반복 클릭이 없는데도 작업이 다시 실행된 경우가 있었다.

반복 입력이 있었던 사례

Chatwoot에서는 버튼을 여러 번 눌렀고, Keycloak과 Shopware에서는 폼을 반복 제출한 뒤 문제가 나타났다.

반복 입력 없이 다시 실행된 사례

Fluent UI에서는 Enter 한 번으로 폼 제출이 두 번 실행됐고, Google Site Kit에서는 인증을 마치고 돌아온 뒤 생성 요청이 다시 실행됐다.

결과도 같지 않았다. Chatwoot과 Shopware에서는 중복 기록이 남았다. Google Site Kit에서는 이미 존재한다는 오류가 잠깐 나타났고, Keycloak에서는 첫 시도가 취소된 뒤 로그인 오류가 발생했다. Fluent UI에서는 폼 제출 동작 자체가 두 번 실행됐다.
