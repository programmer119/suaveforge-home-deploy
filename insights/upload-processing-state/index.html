파일 전송률이 100%가 돼도 서버 작업은 남아 있을 수 있다

브라우저가 파일 전송을 마친 뒤에도 서버에서는 형식 검사, 압축 해제, 미리보기 생성 같은 작업이 남을 수 있다. 화면에서는 파일 전송이 끝난 상태와 실제로 파일을 쓸 수 있는 상태를 구분해 보여줘야 한다.

2026년 8월 31일Insights

큰 파일을 올릴 때 화면에 파일 전송 진행률을 보여주는 서비스가 있다. 전송률이 100%가 되면 브라우저의 파일 전송은 끝난다.

파일 선택
   ↓
브라우저가 서버로 파일 전송
   ↓
전송률 100%
   ↓
서버에서 형식 검사·압축 해제 등 필요한 작업 수행
   ↓
필요한 서버 작업 완료
   ↓
파일 사용 가능

전송률이 100%가 되자마자 완료라고 표시하면 사용자는 파일을 바로 쓸 수 있다고 생각한다. 형식 검사나 압축 해제처럼 사용 전에 필요한 서버 작업이 남아 있다면 아직 완료 상태가 아니다.

화면에서는 파일 전송 성공과 서버 작업 실패를 따로 보여줘야 한다. 파일 전송은 끝났더라도 형식이 잘못됐거나 변환 작업이 실패했다면 사용자가 실패 이유를 확인할 수 있어야 한다.

검수할 때는 진행률이 100%가 되는 순간만 보면 안 된다. 파일 전송이 끝난 뒤 필요한 서버 작업까지 완료되는지 확인한다. 서버 작업이 실패하면 오류 이유가 화면에 표시돼야 한다. 화면에 완료라고 뜬 뒤 파일을 실제로 열거나 사용할 수 있어야 한다.

사용자가 파일을 실제로 쓸 수 있을 때 완료라고 표시해야 한다.
