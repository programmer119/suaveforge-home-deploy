서버 후처리가 있다면 파일 전송률 100%가 곧 완료는 아니다

전송률 100%는 브라우저가 파일 전송을 끝냈다는 뜻일 뿐이다. 형식 검사나 압축 해제처럼 사용 전에 필요한 서버 작업이 있다면 전송 완료와 파일 사용 가능 상태를 나눠 보여줘야 한다.

2026년 8월 31일Insights

큰 파일을 올릴 때 화면에 보이는 100%는 보통 브라우저가 서버로 파일을 다 보냈다는 뜻이다. 그 뒤 서버에서 해야 할 일이 없다면 곧바로 완료로 볼 수 있지만, 후처리가 남아 있는 서비스라면 전송 완료와 사용 가능 상태를 구분해야 한다.

형식 검사나 압축 해제 등 파일을 쓰기 전에 반드시 끝나야 하는 작업이 있다면 전송률 100%에서 바로 완료라고 표시하면 안 된다. 사용자는 완료 표시를 보고 파일을 바로 열 수 있다고 기대하기 때문이다.

파일 전송이 끝난 상태와 이후 서버 작업이 실패한 상태도 구분해야 한다. 형식 오류나 변환 실패를 모두 업로드 실패로 묶지 말고 어느 단계에서 실패했는지 보여주는 편이 낫다.

전송률 100%만 확인하고 끝내면 안 된다. 필요한 서버 작업이 끝난 뒤 파일을 실제로 열거나 사용할 수 있는지 확인한다. 중간 작업이 실패하면 화면에 실패 이유가 표시되는지도 확인한다.

사용자에게 중요한 것은 전송 완료가 아니라 서비스에서 파일을 실제로 쓸 수 있느냐다.
