중간 상태가 남으면 다음 행동까지 막힌다

가입, 취소, 삭제 같은 한 단계가 끝나지 않은 상태로 남으면 사용자는 다음 행동으로 넘어가지 못한다. 반복 사례에서는 기능 하나의 문제가 아니라 이전 상태가 새 행동을 잠그는 구조가 공통으로 나타났다.

2026년 9월 2일Insights

사용자가 막히는 지점은 눈앞의 버튼 하나가 아닐 때가 많다. 앞 단계에서 남은 상태가 다음 행동의 조건으로 연결되면, 한 번의 실패가 여러 화면을 차례로 막는다.

수업을 직접 취소할 수 없어 다음 수업 신청까지 기다려야 했던 사례가 있었고, 가입은 됐지만 실제 이용 화면에서 다른 계정을 요구해 더 진행할 수 없었던 사례도 있었다. 공개 지원 사례에서는 설정이 중단된 뒤 계정은 이미 존재한다고 나오면서도 설정을 이어갈 수 없거나, 로그인과 재가입이 서로 다른 상태를 말해 둘 다 막힌 경우가 있었다. 사이트 삭제가 완전히 끝나지 않아 남은 기록이 이후 복원까지 막은 버그도 보고됐다.

앞 작업이 일부만 끝남
중간 상태가 남음
다음 작업의 조건과 충돌
사용자가 다른 경로로도 진행하지 못함

막힌 화면보다 남은 상태를 찾는다

다음 버튼을 고치는 것만으로는 같은 문제가 다시 생길 수 있다. 먼저 앞 작업이 어떤 상태를 남겼는지, 그 상태를 누가 해제할 수 있는지, 실패하거나 중단됐을 때 복구 경로가 있는지 확인해야 한다.

검수할 때는 정상 완료만 보지 않는다. 가입 도중 창을 닫고 다시 들어오거나, 취소 요청을 남긴 채 다른 신청을 해보거나, 삭제가 일부만 처리된 상태에서 복원을 시도해 본다. 그때 다음 행동이 불필요하게 잠긴다면 흐름 전체를 다시 봐야 한다.
