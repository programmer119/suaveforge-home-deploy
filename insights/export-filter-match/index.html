화면에 적용한 검색 조건은 내려받은 파일에도 그대로 반영돼야 한다

목록에서 날짜와 상태를 좁혀 20건만 보고 있는데 내려받은 파일에 전체 300건이 들어가면 사용자는 다시 걸러야 한다. 내려받은 파일에도 화면의 검색 조건이 그대로 반영돼야 한다.

2026년 8월 31일Insights

관리자 목록에서 검색한 뒤 엑셀이나 CSV를 내려받는 기능은 자주 쓰인다. 내보내기 버튼이 목록 화면에 있으면 사용자는 지금 보고 있는 조건이 파일에도 적용된다고 기대한다.

화면에서 검색 조건 설정
   ↓
목록 20건 조회
   ↓
파일 다운로드 요청
   ↓
서버가 같은 검색 조건으로 데이터를 조회
   ↓
조회한 데이터로 파일 생성

화면과 파일에 서로 다른 검색 조건이 적용되면 문제가 생긴다. 화면에서는 이번 달의 완료 주문만 20건 보이는데 파일에는 전체 주문 300건이 들어갈 수 있다.

정렬 기준도 미리 정해야 한다. 화면이 최신순이라면 파일도 같은 순서로 내보낼지 정해야 한다. 파일 정렬이 화면과 다르면 그 기준을 사용자에게 알려야 한다.

검수할 때는 파일이 만들어졌다는 사실만 보지 않는다. 화면에 표시된 건수와 파일의 데이터 행 수를 비교한다. 파일에서 일부 행을 골라 날짜와 상태가 검색 조건에 맞는지도 확인한다.

사용자가 파일을 내려받은 뒤 같은 조건으로 다시 거르지 않아도 돼야 한다.
