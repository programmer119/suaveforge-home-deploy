화면에 적용한 검색 조건은 내려받은 파일에도 그대로 반영돼야 한다

화면에서 이번 달 완료 주문 20건만 보고 있는데 파일에는 전체 300건이 들어가면 사용자는 다시 걸러야 한다. 파일을 내보낼 때도 현재 조회 조건을 그대로 써야 한다.

2026년 8월 31일Insights

관리자 목록에서 검색한 뒤 엑셀이나 CSV를 내려받는 기능은 자주 쓰인다. 목록 화면의 내보내기 버튼을 누르면 사용자는 현재 검색 조건이 파일에도 적용된다고 기대한다.

화면: 이번 달 + 완료 → 20건
파일: 같은 조건       → 20행

화면에서는 이번 달 완료 주문만 20건 보이는데 파일에 전체 주문 300건이 들어간다면 사용자는 같은 필터를 다시 적용해야 한다. 다운로드 기능이 오히려 일을 하나 더 만드는 셈이다.

파일을 만들 때 서버도 화면의 날짜, 상태, 검색어를 그대로 사용해 데이터를 조회해야 한다. 화면과 파일이 서로 다른 기본값을 쓰지 않는지도 확인해야 한다.

정렬은 서비스 정책에 따라 다를 수 있다. 화면과 파일의 정렬이 다르다면 파일의 정렬 기준을 사용자에게 알려야 한다.

확인 방법은 단순하다. 화면의 건수와 파일의 행 수를 비교하고, 몇 행을 골라 날짜와 상태가 실제 검색 조건에 맞는지 보면 된다.

다운로드한 뒤 다시 같은 필터를 걸어야 한다면 화면의 검색 결과가 파일로 제대로 이어진 것이 아니다.
